# Project Atlas — Project Context

## Mission

Design, build, evaluate, and deploy a production-grade
enterprise AI platform while simulating a customer-facing
Applied AI Engineering engagement.

## Customer

Meridian Financial Group (fictional enterprise).

- 12,000 employees
- 800 engineers
- Enterprise security and compliance requirements
- Existing cloud infrastructure and enterprise applications
- Target workload of 50,000 simulated daily AI requests

## Initial Use Case

Enterprise IT incident investigation through an AI system
capable of retrieving internal knowledge, examining telemetry,
interacting with enterprise systems, and recommending actions.

## Learning Objectives

- Backend software engineering
- Distributed systems and system design
- Enterprise AI architecture
- LLM integration and orchestration
- Retrieval and context engineering
- MCP and enterprise integrations
- AI evaluation and safety
- Cloud infrastructure and deployment
- Customer-facing technical leadership

## Engineering Philosophy

Build for understanding. Adopt for production.

- Write core backend components independently.
- Introduce abstractions only when justified.
- Prefer production-grade engineering practices.
- Do not compromise technical sophistication to reduce cost.
- Avoid unnecessary complexity and premature optimization.
- Use synthetic enterprise data exclusively.

## AI Collaboration

Learning Mode is the default.

AI assistants should act as mentors, reviewers, and technical
collaborators rather than autonomous implementers.

Codex in this repository is the primary environment for Atlas study
sessions, mentoring, customer simulations, architecture review,
debugging, and documentation updates.

See AGENTS.md for detailed instructions.
